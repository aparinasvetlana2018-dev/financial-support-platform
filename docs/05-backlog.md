# Backlog MVP

Приоритет: P0 — необходимо для запуска первого потока; P1 — важно вскоре после запуска; P2 — на будущее.

## 1. Регистрация и доступ

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P0 | Регистрация по e-mail и паролю | Пользователь может создать аккаунт и войти |
| P0 | Подтверждение e-mail кодом | Код действует 5 минут; повторная отправка доступна через 60 секунд |
| P0 | Восстановление пароля | Пользователь получает ссылку и устанавливает новый пароль |
| P0 | Вход по ID | После ввода ID система открывает доступные разделы |
| P1 | Управление сессиями при смене роли | После изменения роли требуется повторный вход |

## 2. Группы и участники

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P0 | Создание группы | Модератор создаёт группу и сохраняет её |
| P0 | Добавление участника в группу | Участник появляется в составе группы |
| P0 | Назначение куратора | Группе можно назначить одного или нескольких кураторов |
| P0 | Карточка участника | Видны данные, статус, роль, комментарий и активность |
| P1 | Перевод участника между группами | История группы сохраняется |

## 3. Чат и форумы

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P0 | Общий чат группы | Участники группы могут обмениваться сообщениями |
| P0 | Форум наставника | Наставник создаёт темы и публикует материалы |
| P0 | Закрепление сообщения или материала | Важное сообщение доступно в архиве/библиотеке |
| P1 | Личные сообщения наставнику | Ученик может написать наставнику в ЛС |
| P2 | Изоляция форумов по потокам | Обсуждения разных потоков не пересекаются |

## 4. Материалы и библиотека

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P0 | Загрузка материала наставником | Поддерживаются файлы, ссылки, видео и тесты |
| P0 | Автосохранение материала в ЛК ученика | При включённой опции материал появляется в библиотеке |
| P0 | Личная библиотека ученика | Ученик видит сохранённые материалы |
| P1 | Пометка «важное» | Наставник закрепляет для всех, ученик — для себя |
| P2 | Публичная библиотека бесплатных материалов | Гость может читать открытые материалы |

## 5. Домашние задания

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P0 | Создание ДЗ наставником | Указываются текст, срок и прикреплённые материалы |
| P0 | Автоматическое попадание ДЗ в раздел ученика | Ученик видит задание, срок и автора |
| P0 | Сдача ДЗ учеником | Ученик загружает ответ или отправляет текст |
| P0 | Проверка ДЗ наставником | Наставник оставляет комментарий и оценку |
| P1 | Статусы ДЗ | Новое, сдано, на проверке, проверено, просрочено |

## 6. Отчёты и расписание

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P0 | Обязательный отчёт по вторникам и пятницам | Ученик может заполнить и отправить отчёт |
| P0 | Просмотр отчётов наставником | Наставник видит отчёты своей группы |
| P0 | Расписание на месяц | Модератор создаёт события с датой и временем |
| P1 | Уведомления о событиях | Участник получает напоминание |

## 7. Модерация и аналитика

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P0 | Список пользователей и статусов | Модератор видит участников, кандидатов и гостей |
| P0 | Присвоение ID и роли | Модератор переводит кандидата в участника |
| P0 | Аналитика воронки | Видны переходы: сайт → регистрация → анкета → обучение |
| P1 | Активность участника | Видны ДЗ, отчёты и посещаемость |
| P2 | Конструктор прав ролей | Модератор может настраивать доступы |
