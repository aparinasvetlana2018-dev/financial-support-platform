# Экраны MVP

## Общие экраны

| Экран | Назначение | Основные элементы |
|---|---|---|
| Главная | Знакомство с проектом | Описание, кнопка «Подать заявку», раздел «Форумы», бесплатные материалы |
| Вход | Авторизация | E-mail, пароль, вход, восстановление пароля |
| Регистрация | Создание аккаунта | E-mail, пароль, подтверждение кодом |
| Подтверждение e-mail | Ввод кода | Поле кода, таймер, кнопка «Отправить снова» |
| Восстановление пароля | Сброс доступа | E-mail, отправка ссылки, новый пароль |

## Гость

| Экран | Назначение | Основные элементы |
|---|---|---|
| Главная гостя | Знакомство с проектом | Описание, кнопка «Подать заявку», бесплатные материалы, форумы |
| Анкета | Первичная заявка | Имя, телефон, e-mail, опыт, потребность, время созвона |
| Чат с модератором | Запись на собеседование | Переписка, уведомления |
| Уведомление о ID | Получение доступа | ID, инструкция по входу |

## Ученик

| Экран | Назначение | Основные элементы |
|---|---|---|
| Ввод ID | Активация доступа | Поле ID, подсказка |
| Личный кабинет | Центр обучения | Прогресс, группа, ближайшие события, ДЗ, отчёты |
| Выбор группы | Переключение между группами | Список доступных групп |
| Чат группы | Общение | Сообщения, вложения, закреплённые сообщения |
| Форумы | Тематические обсуждения | Список форумов, темы, комментарии |
| Библиотека | Материалы | Фильтры, карточки материалов, скачивание/просмотр |
| Домашние задания | Контроль обучения | Задание, срок, статус, отправка, оценка, комментарий |
| Отчёт | Регулярная отчётность | Форма отчёта, история отправок |
| Расписание | События | Календарь/список на месяц, ссылки на встречи |

## Наставник / эксперт

| Экран | Назначение | Основные элементы |
|---|---|---|
| Личный кабинет | Работа с группой | Группа, ближайшие события, ДЗ на проверку |
| Чат группы | Общение и публикации | Сообщения, вложения, закрепление, отправка в ЛК |
| Мой форум | Ведение пространства | Создание тем, редактирование, модерация комментариев |
| Материалы | Публикация | Загрузка файла, видео, теста, ссылки; переключатель «сохранять в ЛК» |
| ДЗ | Создание и проверка | Создание задания, список работ, комментарий, оценка, статус |
| Отчёты | Контроль прогресса | Список отчётов, фильтры, просмотр |

## Админ-модератор

| Экран | Назначение | Основные элементы |
|---|---|---|
| Дашборд | Общая картина | Количество участников, групп, заявок, активность |
| Пользователи | Управление людьми | Поиск, фильтры, статус, роль, карточка участника |
| Заявки и кандидаты | Отбор | Анкета, статус, собеседование, решение |
| Группы | Управление потоками | Создание, состав, кураторы, редактирование |
| Чаты и форумы | Модерация | Список, модерация, закрепление, удаление нарушений |
| Расписание | Управление событиями | Создание и редактирование занятий |
| Аналитика | Метрики | Воронка, активность, ДЗ, отчёты, посещаемость |
| Публикации | Контент | Статьи, новости, информация, отложенная публикация |
