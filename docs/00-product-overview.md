# Обзор продукта

## О проекте

Проект «Своя финансовая опора» — благотворительная образовательная платформа. Целевая аудитория — люди, оказавшиеся в сложной финансовой и жизненной ситуации. Платформа даёт им:

- знания от разных специалистов;
- учебные материалы (архив);
- психологическую поддержку (через сообщество и работу групп).

Задача платформы — провести человека по пути: гость → заявка и анкета → собеседование → подписание документов → распределение в группу → обучение в группе.

## Основные сущности

| Сущность | Описание |
|---|---|
| Группа | Учебная группа: ученики + преподаватели. Если групп больше одной, ученик выбирает группу |
| Чат | Общий чат группы для связи и общения с преподавателями и учениками |
| Форум | «Классная комната» преподавателя. Узконаправленный, тема обсуждения определяется преподавателем, который его создал. Другие преподаватели в форуме могут отсутствовать |
| Архив материалов | Статьи и важные для ученика высказывания. Попадает из чата и форумов через пометку «важное» |
| Домашнее задание (ДЗ) | Публикуется в чате с пометкой «ДЗ» и датой сдачи; автоматически попадает в «сумку ДЗ» с указанием срока и автора |
| Сумка ДЗ | Личное хранилище домашних заданий ученика |
| Доска расписания | Даты и время событий на ближайший месяц. Модерируется только модератором |
| Отчёт | Отчёт о прогрессе обучения. Заполняется во вторник и пятницу, обязателен |
| Анкета | Заполняется гостем при подаче заявки (для регистрации не обязательна) |

## Правила пометки «важное»

- Пометку может поставить **преподаватель** — материал закрепляется у всех участников.
- Пометку может поставить **ученик** — материал закрепляется только у него.

## Правила домашних заданий

- Публикация в чате группы с пометкой «ДЗ» и сроком сдачи.
- Публикация сразу попадает в сумку ДЗ учеников с пометкой сроков и указанием преподавателя.
- Редактировать и проверять ДЗ может **только тот преподаватель, который его задал**.

## Аналитика

Воронка:

1. посещение сайта → регистрация;
2. регистрация → подача анкеты;
3. анкета → перешли к обучению;
4. начали обучение → закончили обучение.

По участнику (в личной карточке):

- процент вовремя выполненных отчётов/ДЗ от несвоевременно выполненных;
- процент невыполненного от всего объёма;
- процент посещаемости.
