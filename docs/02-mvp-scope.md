# Объём первой версии (MVP)

## Входит в MVP

### Для ученика (главный экран платформы)

1. **Чат группы** — связь и общение с преподавателями и учениками.
2. **Архив материалов** — статьи и важные высказывания с пометкой «важное».
3. **Доска расписания** — даты и время событий на ближайший месяц.
4. **Сумка домашних заданий** — ДЗ со сроками и указанием преподавателя.
5. **Форумы преподавателей** — «классные комнаты».
6. **Выбор группы** — когда групп больше одной.
7. **Отчёт** — о прогрессе обучения (вторник и пятница, обязательный).

### Для модератора

1. Группа 0 со списками всех зарегистрированных участников и их статусами.
2. Вкладки групп: участники и их редактирование.
3. Аналитика платформы и участников (базовая).
4. Карточки участников.
5. Список посетителей (заявки + запись на собеседование).
6. Создание и редактирование расписания.

### Общее

- Регистрация и вход.
- Анкета гостя.
- Путь гость → участник (см. `03-user-flows.md`).

## Не входит в MVP (отложено)

- Электронная подпись и авторизация через Госуслуги (пока подписание документов фиксируется вручную).
- Чат-бот для записи.
- Продвинутая аналитика (детальные графики, экспорт).
- Изоляция потоков/групп между собой сверх необходимого.

## Критерии готовности MVP

- Гость может зарегистрироваться, заполнить анкету и попасть в список посетителей модератора.
- Модератор может подтвердить гостя участником и распределить в группу.
- Ученик видит чат группы, форумы, ДЗ, расписание, архив и заполняет отчёты.
- Преподаватель создаёт форум, публикует материалы и ДЗ, проверяет свои ДЗ, видит отчёты.
