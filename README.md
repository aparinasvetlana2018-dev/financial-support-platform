# Своя финансовая опора

Благотворительная образовательная платформа для людей, оказавшихся в сложной финансовой или жизненной ситуации. Проект объединяет обучение, материалы специалистов и психологическую поддержку в одной системе.

## Стек

- Next.js + TypeScript
- PostgreSQL + Prisma
- S3-совместимое файловое хранилище
- Figma для дизайна интерфейсов

## Быстрый старт

1. Установите зависимости:

```bash
npm install
```

2. Скопируйте переменные окружения:

```bash
cp .env.example .env
```

3. Укажите строку подключения к PostgreSQL в `.env`.

4. Создайте структуру базы данных:

```bash
npm run db:push
```

5. Запустите проект:

```bash
npm run dev
```

6. Откройте `http://localhost:3000`.

## Текущий каркас

- Главная страница с кнопкой «Подать заявку».
- Страница регистрации.
- Страница входа.
- Личный кабинет с вводом ID участника.
- Базовая Prisma-схема: пользователи, группы, участие, чаты, форумы, материалы, ДЗ, отчёты и расписание.
