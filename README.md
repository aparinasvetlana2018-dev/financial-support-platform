# Своя финансовая опора — платформа обучения

Благотворительный проект: платформа, на которой проходит основная часть обучения для людей, попавших в сложную финансовую и жизненную ситуацию. Помощь предоставляется в виде знаний от разных специалистов, учебных материалов и психологической поддержки.

Соцсети для связи: https://vk.ru/freebreathing_ano

## Ключевая идея

Одна платформа с разделением доступа по ролям, а не несколько отдельных систем.

| Роль | Кратко |
|---|---|
| Модератор (админ) | Собеседования, присвоение статусов, группы, расписание, модерация чатов/форумов, аналитика |
| Преподаватель | Свой форум, учебные материалы, ДЗ (публикация и проверка), просмотр отчётов |
| Ученик | Чат группы, форумы, ДЗ, отчёты, архив материалов, расписание |
| Гость | Ознакомление с сайтом, регистрация, анкета, запись на собеседование |

Подробности — в папке `docs/`.
